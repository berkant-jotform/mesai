# Downloads and installation

## Get the source

Open the repository, choose **Code → Download ZIP**, and extract it. If the repository is private, sign in with an account that already has access. A source ZIP contains the project files; it does not install Node.js, Python, native tools, provider keys or models.

Follow [Getting started](GETTING_STARTED.md) for this project. Keep the extracted folder somewhere you can find again. Do not launch directly from an archive preview.

## Small source bundle

The release contains the static project files through GitHub’s Source code archive. No executable installer, dependency folder or model weights are attached. Follow the getting-started guide after extracting it.

## This project

Use [the setup page](https://berkant-jotform.github.io/mesai/) for normal use. A lightweight [source release](https://github.com/berkant-jotform/mesai/releases/latest) is available for developers. Choose **Source code (zip)**; Python/Node are needed only for local development checks.

## Sharing

This repository is public. Never attach credentials, private account exports or personal data to a release.
