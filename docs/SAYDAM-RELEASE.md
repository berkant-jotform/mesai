# Saydam release notes

From 3.4.0 Saydam is built from the modular source in `source/mesai/src` like every other theme. The 3.3.1 and 3.3.2 repairs (made on a compiled export at the time) are part of that source; `source/mesai/exports/` is no longer used.

See [Saydam QA](SAYDAM-QA.md) for the 3.3.x checks.
